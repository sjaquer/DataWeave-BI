# **App Name**: DataWeave BI

## Core Features:

- Data Import: Import data from Google Sheets and Excel files. Support automatic refresh of data for live dashboards.
- Inventory Movement Analysis: Analyze inventory movement data, calculating key metrics such as stock turnover rate, and identifying slow-moving items. Summarize key insights on warehouse efficiency, and suggest areas for optimization. It will use a tool to choose which insights to share.
- Sales Performance Dashboard: Display interactive charts and graphs for sales analysis, including sales trends, product performance, and regional sales breakdowns.
- KPI Monitoring: Monitor key performance indicators (KPIs) across different departments (sales, marketing, logistics). Display performance against targets and historical data.
- Demographic Analysis: Analyze customer demographics, providing insights into customer segmentation and behavior patterns. Helps tailor marketing efforts and product development.
- Customizable Dashboards: Enable users to create custom dashboards by selecting specific data visualizations and metrics relevant to their roles.

## Style Guidelines:

- Primary color: Deep sky blue (#3498db) for a professional, trustworthy feel.
- Background color: Very light grey (#f2f4f7), almost white, for a clean and modern look.
- Accent color: A muted greenish-blue (#2ecc71) to indicate growth and positive trends.
- Body and headline font: 'Inter', a sans-serif font, providing a modern and readable interface.
- Use clean, minimalist icons to represent different data types and metrics.
- Design a responsive layout that adapts to different screen sizes and devices, ensuring accessibility and usability.
- Subtle transitions and animations for loading data and updating charts to provide a smooth user experience.
